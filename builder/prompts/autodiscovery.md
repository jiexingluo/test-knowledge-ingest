# 自动发现提示词

你正在分析来自 ATE（自动测试设备）测试项目的文件。你的任务是根据文件在测试程序中的角色对其进行分类。

## 分类规则

### 源文件（高优先级）
- 扩展名：.cpp, .h, .c, .py, .bas, .cls, .frm, .cs
- 路径包含 "Source/" 或 "src/" 的文件
- 这些文件包含实际的测试逻辑

### 测试计划（高优先级）
- 文件名包含：testplan, test_plan, "test plan", TPD_
- 这些文件描述测试策略和覆盖意图

### 数据表（高优先级）
- 文件名包含：datasheet, data_sheet, spec
- 这些文件提供设备规格和约束条件

### 原理图（高优先级）
- 文件名包含：schematic, 原理图
- 扩展名：.dsn, .brd
- 这些文件显示硬件连接

### 构建元数据（中优先级）
- 扩展名：.sln, .vcproj, .vcxproj, .dsp, .dsw, .csproj
- 项目结构信息

### 编译产物（低优先级 — 跳过分析）
- 扩展名：.dll, .pgs, .pfl, .ldf, .exe, .obj, .lib
- 不分析这些文件

## 任务

给定下面的文件列表，对每个文件进行分类，并识别任何缺失的关键文件类型（测试计划、数据表、原理图）。

返回一个包含分类结果的 JSON 对象。
