## 分类规则

1. **新的** (`new`)：任何现有知识库条目都未涵盖的知识或模式
   - 完全新的主题领域
   - 以前未见过的新实体类型模式

2. **加强** (`strengthen`)：支持现有知识库条目的新证据
   - 在其他项目中观察到相同的规则
   - 现有模式的更多示例
   - 操作：将证据附加到现有条目，可能扩大范围

3. **改进** (`refine`)：对现有条目的更精确描述
   - 更好的措辞或更具体的条件
   - 发现的额外细微差别
   - 操作：生成问题询问用户是否应进行更新

4. **冲突** (`conflict`)：新数据与现有知识库条目相矛盾
   - 对同一问题的不同方法
   - 矛盾的参数值
   - 操作：生成问题，显示双方的证据供用户解决

## 输出

返回一个 DiffReport JSON 对象，每个类别都有数组。
